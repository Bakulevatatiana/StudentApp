# Приложение поиск студентов.
## Над приложением работала: 
Татьяна Бакулева
## Список используемых технологий:

Java, Maven Spring Boot, Spring Web, Spring Data, Spring JPA, Lombok REST 

База данных:
PostgreSQL Liquibase
## Функционал: 
 -Получить информацию об одном студенте
- Получить информацию о всех студентах
- Получить информацию о студентах одной группы, отсортированных по ФИО
- Поиск студентов, отсортированных по ФИО по параметрам
